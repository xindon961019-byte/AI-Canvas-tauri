# UI Kit 滚动 Tabs 公用组件实施计划

## 目标与范围

状态：用户已确认范围，实施与验证完成。任务类型：架构收敛（资产库局部控件抽取为公用 UI 控件）。

将资产库现有下划线页签、计数徽标、横向滚动与弹簧越位回弹统一为 `shared/Tabs.tsx`。资产库和 UI Kit 预览都使用真实组件，样式统一到 `ui-kit.css`。本次只迁移资产库，不批量替换其他业务页签；不新增依赖、不删除文件、不修改原生能力或持久化状态。

## 公用接口与行为

- 受控接口：`items`、`value`、`onChange`；每项包含 `value`、`label`、可选 `count` 和 `disabled`。支持 `size`、`className` 与可访问名称。
- 保留截图中的标签排版、下划线、计数徽标，以及默认和紧凑尺寸。所有颜色引用 `base.css` 的变量，适配深浅主题。
- 选中非最后一项时尽量居中，最后一项滚到最右侧；目标受实际可滚动范围约束。
- 沿用约 0.5 秒到位、`bounce: 0.35` 的非线性弹簧；滚动边界用内容层呈现最多 12px 的越位回弹。
- 连续选择、手动滚动、指针交互和卸载时停止旧动画并清理临时位移；系统减少动态效果时直接定位。
- 采用 `tablist` / `tab`、`aria-selected` 和单一焦点入口；左右方向键及 Home/End 导航并跳过禁用项。资产抽屉现有 Tab 收起语义仍由宿主控制。
- 组件只管理展示、焦点和滚动，不依赖资产库、Store 或文件服务。

## 实施顺序与验证

1. 确认以上范围后抽取组件与样式，保持业务行为和现有动效参数。
2. 资产库接入，核对抽屉和大弹窗布局及业务页签切换。
3. 添加 UI Kit 目录和真实交互样例，可在深浅主题中切换查看。
4. 运行改动文件 ESLint、`npm run typecheck`、`npm run test:typecheck`，以及 Tabs 和资产库定向 Vitest。
5. 若可使用实际界面，核对中间项居中、末项靠右、两端回弹和快速连续点击；未进行的视觉验收须明确保留为缺口。
6. 更新本计划的实际验证结论，不将记录写入 Agent 实施方案。

## 实施结果与实际验证

- `Tabs.tsx` 已成为资产库与 UI Kit 的共同入口；局部页签动画及样式已从资产库移出，资产库保留现有业务切换与布局。
- UI Kit 增加独立 Tabs 目录和三组真实组件样例，覆盖计数、紧凑尺寸、窄容器、无计数与禁用状态。
- 六个变更的 TSX 文件定向 ESLint、`npm run typecheck`、`npm run test:typecheck` 和 `git diff --check` 均通过。
- 定向 Vitest 共 33 项通过：公用控件 12 项、资产库 21 项，覆盖定位、边界回弹、键盘导航、动画中断、尺寸变化和减少动态效果等。
- 本地浏览器实测 UI Kit 深浅主题、中间项居中、末项靠右、边界越位后清除位移，以及方向键跳过禁用项；中间项居中误差小于 1px。
- 主应用大弹窗与抽屉布局实测正常；抽屉末项定位正确，从页签按 Tab 仍可收起。原生 Tauri 独立窗口未单独现场验收。
- 文本文件保持 UTF-8，资产库源文件保留原有 BOM；无新增依赖、文件删除或原生能力变更。

## 影响与回滚

影响范围是资产库页签呈现、UI Kit 样例和新增公用控件；业务切换仍通过现有 `switchTab`。主要风险是样式迁移造成尺寸或主题偏差，以及键盘焦点与抽屉快捷键冲突，对应定向回归和视觉验收。

当前未提交的 `AssetsPanel.tsx` 包含本会话已完成的滚动修复，必须完整保留其行为。回滚只恢复抽取前的局部 JSX、样式和动画，不对文件整体执行 Git 还原，不覆盖本会话或其他任务已有改动。新增文件可先保留为未引用状态；若需删除文件，另按项目规则确认。
