# 资产图片批量反推实施计划

**目标：** 在资产库工具栏批量反推当前筛选图片的提示词与标签，成功后完整替换保存，支持 3–5 路并发、停止和手动重试。

**实现：** 复用文本视觉模型选择器、反推服务、Store 图片保存 Action 与现有图片身份校验；队列只在当前资源窗口运行。提示词和标签共用一个 IndexedDB 事务，比较图片记录版本和标签基线，保留参考图、历史及磁盘原图。

**技术：** React、TypeScript、现有 UI Kit、IndexedDB，不新增依赖、object store 或原生权限。

## 范围与步骤

1. `src/types/assetImage.ts`：批量条目、状态与标签替换基线。
2. `src/services/indexedDbService.ts`、`src/services/fs/assetImageMetadata.ts`、`src/store/store.ui.ts`：可选原子替换，取消及冲突保护，成功后通知最近资源刷新。
3. 新增 `src/services/assetImageBatchReverse.ts`：有界 worker 队列，调用前读取身份和版本，调用后复核内容并保存；失败隔离，不自动重试。
4. 新增 `src/components/assets/AssetImageBatchReverseDialog.tsx`：复用 UI Kit 紧凑横排列表，图片勾选、统一模型、3/4/5 并发、逐项状态、停止与失败重试；只读识别已有提示词并标记，默认仅勾选未有提示词的图片，支持手动选择覆盖。
5. `src/components/AssetsPanel.tsx`：添加按钮左侧入口，冻结筛选结果和项目归属，成功后更新标签；关闭或切换资源范围卸载队列。
6. `doc/文件与存储模块.md`：维护入口及边界。

## 验收与回滚

- 按用户要求不运行自动化测试、浏览器验收或真实模型调用；验收交由用户。
- 用户验证：当前筛选覆盖所有分页图片；勾选与模型切换；3/4/5 并发上限；提示词和标签完整覆盖；参考图保留；失败项不变；停止后无迟到写回；手动重试失败/停止项；关闭与范围切换取消；原图改名/替换与标签修改冲突；深浅主题。
- 检查只限源码差异、调用链和 UTF-8 编码。回滚仅撤销本次差异，保留既有修改；不改变 schema，不删除用户数据。
