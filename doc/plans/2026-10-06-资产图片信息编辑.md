# 资产图片信息编辑

状态：第一阶段已实现，桌面原生文件操作待现场验收。

## 范围与验收

- 产品能力：资产全屏预览中编辑、保存或取消提示词；添加本地参考图、缩略图查看及移除关联。原生成参数继续只读，用户编辑不改写生成历史或资产标签。
- 第一阶段参考图由用户手动添加。生成链未自动记录原始输入参考图，旧历史未保存的参考图不能恢复。
- 草稿未保存时，关闭或切换图片需要用户选择；复制取消、内容变化、保存冲突和目录故障保留草稿。事务已提交后，参考图预览读取失败不会误报保存失败。
- 已批准 14 个文件：`AssetImagePreview.tsx`、`assetImageDetails.ts`、`fs/assetImageMetadata.ts`、`types/assetImage.ts`、`indexedDbService.ts`、`fileService.ts`、`store.ui.ts`、`panels.css`，四个图片信息相关测试文件，本计划和文件与存储模块文档。不新增依赖、数据库版本或原生命令，不改变安全配置。

## 存储决策

- 提示词及关联保存在现有 IndexedDB `metadata` 的 `asset-image:` 记录中。新记录键由资产 ID 与内容摘要组成，事务内比较 `revision`，并发首次保存也不能静默覆盖。不同内容的旧记录分别保留。
- 参考图先经既有可取消流式传输复制至当前数据根目录的 `asset-image-references/`，校验副本后再提交记录。数据库只存副本相对路径、名称、内容摘要和大小；原始选择路径仅存在于调用期，不持久化预览 URL、控制器或原图绝对路径。
- 使用已有资产索引定位，同时以固定 256 KiB 块的 SHA-256 链复核完整内容。算法含版本种子及总字节数，不能当作普通文件 SHA-256；短读取不会影响结果。不信任 size/mtime 作为内容证据，不在常规目录扫描中额外哈希全部素材。
- 采用独立记录与托管副本，避免外部只读目录无法写旁车文件、修改原图影响内容或参考图源文件移动后失联。代价是复制外部素材目录不会携带应用信息；备份需同时包含数据库和托管副本。随图导出、自动采集生成参考图和离线记录管理不属于本阶段。

## 外部文件变化

| 情况 | 处理 |
|---|---|
| 同一资产改名或移动，内容一致 | 复核内容后复用信息；保存后更新显示名与资产关联 |
| 新资产 ID、内容一致 | 只在唯一旧记录且旧索引位置明确不存在时找回；多个候选不猜测 |
| 同内容复制，旧文件仍在 | 不自动继承另一个资产的信息 |
| 原图删除 | 保留记录及参考图，不自动清理；恢复或重新添加后再尝试内容匹配。本阶段没有独立离线记录管理界面 |
| 同路径被另一张图片替换 | 内容摘要不符时不套用旧编辑信息，旧记录仍保留；有已绑定记录时也抑制旧路径历史的显示 |
| 权限不足 | 不能当作删除；报告读取失败，不扩大授权 |
| 托管参考图缺失、替换或不可访问 | 保留关联并显示不可用，不替换成其他图片 |

旧生成历史仅按原有路径/媒体地址匹配；未曾保存内容绑定记录的旧图片，无法追溯验证该历史是否属于后来替换的同路径文件。此限制不能靠文件名推断解决。

## 故障与回滚

- 保存失败不删除旧记录或文件；复制成功但事务失败可能留下未关联副本。移除参考图仅删关联，不自动删除磁盘文件；没有后台垃圾回收。
- 数据根目录在保存期间变化则拒绝提交。切换根目录后，未迁移的旧副本显示不可用；相对路径不代表自动迁移，恢复原目录或迁移完整数据可重新读取。
- 可撤销本批差异；保留既有目录/剪贴板/预览改动。旧应用忽略新 `asset-image:` 记录，托管副本保留；不执行数据或文件删除回滚。

## 实际验证

- 9 个测试文件 114 项通过：包含完整内容与短读校验、改名找回、原文件存在的复制隔离、同名替换、歧义及权限失败、参考图副本校验/缺失、保存取消、移除只删关联、事务并发冲突、历史与标签保护、Store Action、草稿关闭与参考图预览，以及资产目录、图片/视频预览和数据库回归。
- 应用类型、定向 ESLint、UTF-8 与差异检查通过。完整测试类型检查仍受既有 `HiddenFilmSet.tsx` 定时器的 `number` / `Timeout` 类型错误阻塞；不修改无关吉祥物代码。
- 隔离浏览器挂载真实预览、Store 和 IndexedDB，使用示例图片及模拟文件选择/复制检查编辑、参考图放大、保存、关闭确认与键盘焦点；深浅主题、参考图命中区域和 640×600 上下布局无横向溢出已验证。浏览器模拟不代表 Tauri 原生选择、授权与流式复制已完成现场验收；真实桌面关闭重开、改名/删除及目录迁移仍待验收。
