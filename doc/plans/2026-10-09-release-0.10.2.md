# 0.10.2 发布

日期：2026-10-09。目标版本：`v0.10.2`。比较基准：上一正式版本 `v0.10.1`。

## 范围

- CCC 设置及节点/对话模型菜单统一入口，分组连接与凭据身份保持独立；已提交并推送。
- 纳入 v0.10.1 后已合入的帧动画、透明预览缓存、文档改名、生成特效、RunningHub 参考图、分集对话压缩及英文文案更新。发布说明以提交和源码差异为依据。
- 同步五处应用/锁文件版本、四语言 README 徽章、站点版本与说明书的 CCC 操作；文档主体沿用 0.10.1 核对基线，不改写历史验收结论。Release 工作流仅同步名称与正文，不改构建矩阵、权限或安全配置。
- 修复已有跨环境测试误报：生成特效帧摘要统一到 1e-9 精度，基准从原 npm 0.3.1 包独立取得；CSP 测试按 HTML 解析规则规范换行，不修改应用安全策略。
- 不新增依赖、不删除文件、不迁移配置。

## 发布门禁与状态

- CCC 定向 122 项测试、应用/测试类型与定向 ESLint 通过，已在 Windows Tauri 桌面核对统一卡片、分组管理和模型菜单。

- 17 个发布文件严格 UTF-8、131 处本地 Markdown 链接、11 张内嵌截图字节不变、HTML 锚点和脚本语法、YAML 与差异检查通过；版本一致，发布正文逐字一致，依赖解析、工作流构建及 Tauri 安全配置保持不变。
